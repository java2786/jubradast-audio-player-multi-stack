# Jabardast Music App

Welcome to the **Jabardast Music App** repository! This project is a feature-rich, custom music web application built step-by-step for educational purposes. It demonstrates how to integrate the **YouTube IFrame API** to build custom audio/video controls, handle dynamic playlist rendering, and implement state management across different frontend architectures.

---

## Project Structure

This repository is organized into progressive parts, allowing learners to explore the project across vanilla web standards and modern frontend frameworks:

```text
Jabardast-Music-App/
├── 📁 01-html-css-js/        # Pure HTML, CSS, and Vanilla JavaScript Implementation
├── 📁 02-react-version/      # Modern Component-Driven Version built with React
├── 📁 03-angular-version/    # Enterprise-Structured Version built with Angular
└── 📄 README.md              # Project Documentation
```

---

## Key Features

- **YouTube IFrame Integration:** Embedding YouTube video players while keeping video hidden and handling playback purely through custom UI controls.
- **Dynamic Playlist Rendering:** Loading song lists dynamically from data arrays and attaching event listeners.
- **Real-time State Management:** Displaying active track info and instantly updating the UI when a song is selected.
- **Modern CSS Styling:** Built using CSS Variables (`:root`), `color-mix`, smooth hover transitions, keyframe pulse animations, custom scrollbars, and fully responsive media queries.
- **Multi-Framework Learning:** Same application concept built across Vanilla JS, React, and Angular to compare paradigms.

## Getting Started

To run any version locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/java2786/Jabardast-Music-App.git
   ```
2. Navigate to the desired part folder (e.g., `01-html-css-js`).
3. Open `index.html` in your browser or use a live server extension (like VS Code Live Server).
